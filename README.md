# Caderno-Tem-tico-Guerra-e-os-Conflitos-Armados-
Neste projeto, criei um Caderno Temático focado no entendimento de 'Guerra e Conflitos Armados' utilizando a ferramenta NotebookLM. Realizei a curadoria de 5 fontes estratégicas (entre livros e artigos acadêmicos) e apliquei técnicas de Engenharia de Prompts para extrair análises profundas sobre as causas e impactos históricos dos conflitos.
